\begin{abstract}
This document presents a self-contained technical description of the supervised learning algorithm \textit{Random Forest}. It analyses the problem of overfitting in individual decision trees, variance reduction through bootstrap aggregation (Bagging), and the decorrelation mechanism based on the random selection of feature subspaces. It also covers the mathematical formulation of Gini impurity, the \textit{Out-Of-Bag} (OOB) error estimate, a structural diagram of the prediction workflow, a comparison table, and a concise Python implementation using \texttt{scikit-learn}.
\end{abstract}

\section{Introduction}
Individual decision trees (CART) are intuitive, non-parametric models; however, they suffer from high variance and a strong tendency to overfit. Introduced by Leo Breiman, the \textit{Random Forest} algorithm overcomes these limitations through an \textit{ensemble learning} approach. By combining a collection of decision trees trained independently and in parallel, the model substantially reduces prediction error in both classification and regression tasks.

\section{Mathematical Foundations}

\subsection{Gini Impurity Criterion}
To build each node of a tree, the algorithm searches for the feature and threshold that maximise the purity of the resulting subsets. The Gini impurity $G$ of a node is formally defined as:
\begin{equation}
G = 1 - \sum_{k=1}^{K} p_k^2
\end{equation}
where $K$ is the total number of classes and $p_k$ is the proportion of observations in that node belonging to class $k$.

\subsection{Bagging and Random Subspaces}
Given a training set $D$ with $N$ observations and $M$ features:
\begin{enumerate}
    \item $B$ \textit{bootstrap} samples are drawn, each consisting of $N$ observations sampled from $D$ with replacement.
    \item In each tree $T_b$ ($b = 1, \dots, B$), a random subset of $m \le M$ features is selected at every node split (typically $m = \sqrt{M}$ for classification and $m = M/3$ for regression).
    \item For a new observation $x$, the final classification prediction $\hat{Y}(x)$ is obtained by majority vote:
\end{enumerate}

\begin{equation}
\hat{Y}(x) = \text{mode} \left\{ T_1(x), T_2(x), \dots, T_B(x) \right\}
\end{equation}

\subsection{Out-Of-Bag (OOB) Error Estimate}
Because sampling is done with replacement, approximately $36.8\%$ of the data is not used to build each individual tree (the \textit{Out-Of-Bag} data). This provides an internal, unbiased estimate of the generalisation error without the need for a separate validation set or cross-validation.

\section{Python Implementation}
The following Python snippet shows how to instantiate and train the model using the \texttt{scikit-learn} library:

\begin{lstlisting}[language=Python, caption={Using RandomForestClassifier in Python.}, label={code:rf_script}]
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import make_classification

# 1. Generate a synthetic dataset
X, y = make_classification(n_samples=1000, n_features=10, random_state=42)

# 2. Instantiate the model with 100 trees and m = sqrt(M)
rf = RandomForestClassifier(n_estimators=100, max_features='sqrt', oob_score=True, random_state=42)

# 3. Train and evaluate the OOB score
rf.fit(X, y)
print(f"Estimated OOB error: {1 - rf.oob_score_:.4f}")
\end{lstlisting}

\section{Conclusion}
\textit{Random Forest} has established itself as one of the most versatile algorithms in Data Science. By introducing two sources of randomness (in the samples and in the features), it decorrelates the individual trees and maximises accuracy without overfitting.
